# Hyperparameter Tuning

**Level:** Intermediate | **Prasyarat:** Python, pandas, dasar Machine Learning

## Learning Objectives

Memahami hyperparameter, membedakan Grid Search dengan Randomized Search, membaca hasil validasi, dan menghindari overfitting pada pemilihan parameter.

## 1. Parameter vs Hyperparameter

**Parameter model** dipelajari saat training, misalnya koefisien regresi. **Hyperparameter** diatur sebelum training, misalnya `max_depth` pada Decision Tree dan jumlah pohon `n_estimators` pada Random Forest.

![Kurva hyperparameter tuning](/img/machine-learning/hyperparameter-tuning.png)

*Ilustrasi hipotetis: semakin kompleks pohon, akurasi train bisa naik terus meski akurasi validasi justru turun.*

## 2. Grid Search dan Randomized Search

| Metode | Cara mencari | Kelebihan |
| --- | --- | --- |
| Grid Search | Menguji semua kombinasi pada grid | Menyeluruh untuk ruang kecil |
| Randomized Search | Mengambil sejumlah sampel konfigurasi | Efisien untuk ruang besar |

## 3. Contoh GridSearchCV (Colab/Jupyter)

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split, GridSearchCV, StratifiedKFold
from sklearn.tree import DecisionTreeClassifier

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=42
)
search = GridSearchCV(
    DecisionTreeClassifier(random_state=42),
    param_grid={'max_depth': [2, 3, 4, 5], 'min_samples_leaf': [1, 2, 4]},
    cv=StratifiedKFold(n_splits=5, shuffle=True, random_state=42),
    scoring='accuracy', n_jobs=-1
)
search.fit(X_train, y_train)
print('Best parameters:', search.best_params_)
print('CV score:', search.best_score_)
print('Test score:', search.score(X_test, y_test))
```

Perhatikan: `GridSearchCV` hanya menggunakan data train saat memilih kombinasi. Test set dievaluasi sekali setelah pemilihan selesai.

## 5. Common Mistakes

- Memilih berdasarkan skor training tertinggi.
- Mencoba terlalu banyak konfigurasi sambil terus mengintip hasil test.
- Menganggap skor terbaik di satu dataset pasti terbaik di semua dataset.
- Mengabaikan waktu komputasi dan reproducibility (`random_state`).
