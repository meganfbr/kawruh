# Principal Component Analysis

**Level:** Beginner–Intermediate | **Course:** Machine Learning


**Principal Component Analysis (PCA)** adalah metode reduksi dimensi yang merangkum variasi data ke arah baru yang disebut *principal components*. PCA merupakan transformasi linear, **bukan** algoritma clustering.

## Tujuan Pembelajaran

- Menjelaskan tujuan reduksi dimensi.
- Memahami principal component dan explained variance.
- Menerapkan PCA setelah scaling dan menghindari kebocoran data.

## 1. Intuisi Visual

![Proyeksi PCA dua dimensi dari data simulasi tiga fitur](/img/machine-learning/pca-projection.png)

*Gambar: proyeksi tiga fitur menjadi dua komponen utama. Persentase pada sumbu menunjukkan proporsi variasi yang dijelaskan pada data simulasi.*

Sumbu baru dipilih agar komponen pertama menangkap variasi terbesar dan komponen berikutnya menangkap variasi terbesar yang tersisa dalam arah tegak lurus.

## 2. Mengapa Reduksi Dimensi?

- Memudahkan visualisasi data dengan banyak fitur.
- Mengurangi redundansi jika fitur-fitur sangat berkorelasi.
- Menyederhanakan sebagian pipeline, tetapi tidak selalu meningkatkan performa model.

PCA sensitif terhadap skala: fitur dengan rentang angka lebih besar berpotensi mendominasi. Standardisasi sering membantu ketika satuan fitur berbeda.

## 4. Praktik PCA scikit-learn (Colab/Jupyter)

```python
from sklearn.datasets import load_iris
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

X = load_iris().data
X_scaled = StandardScaler().fit_transform(X)
pca = PCA(n_components=2)
X_2d = pca.fit_transform(X_scaled)
print("Bentuk awal:", X.shape)
print("Bentuk setelah PCA:", X_2d.shape)
print("Explained variance:", pca.explained_variance_ratio_)
```

Untuk eksperimen dengan train/test, *fit* scaler dan PCA hanya pada training set, kemudian gunakan `transform()` untuk validation/test. Cara mudah adalah menggunakan `Pipeline` scikit-learn.

## 5. Common Mistakes

- Menganggap PC1 selalu fitur asli yang paling penting; komponen adalah kombinasi linear dari fitur.
- Menganggap PCA selalu meningkatkan model; coba bandingkan dengan baseline tanpa PCA.
- Melakukan PCA pada seluruh dataset sebelum split untuk evaluasi prediktif.
