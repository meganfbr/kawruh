# Machine Learning Pipelines

**Level:** Intermediate | **Prasyarat:** Python, pandas, dasar Machine Learning

## Learning Objectives

Mampu menjelaskan fungsi Pipeline, cara mencegah kebocoran preprocessing, serta memahami hubungan Pipeline dengan cross validation.

## 1. Kenapa Perlu Pipeline?

Dalam proyek nyata, data sering memerlukan imputasi dan scaling sebelum masuk ke model. **Pipeline** menggabungkan langkah-langkah ini supaya urutannya konsisten saat training dan prediksi.

![Alur pipeline](/img/machine-learning/ml-pipeline.png)

*Gambar: alur dari data training ke preprocessing dan model. Perhitungan parameter preprocessing hanya boleh menggunakan data train.*

## 2. Contoh Pipeline (Colab/Jupyter)

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.pipeline import Pipeline
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=42
)
pipe = Pipeline([
    ('imputer', SimpleImputer(strategy='median')),
    ('scaler', StandardScaler()),
    ('model', LogisticRegression(max_iter=1000)),
])
pipe.fit(X_train, y_train)
print('Test accuracy:', pipe.score(X_test, y_test))
```

Untuk kolom campuran numerik dan kategori, gunakan `ColumnTransformer` agar strategi scaling dan encoding berbeda sesuai jenis fitur.

## 3. Mengapa Urutan Itu Penting?

Misalnya nilai yang hilang diisi menggunakan rata-rata dari training set. Rata-rata tersebut disimpan saat `fit()` dan dipakai kembali saat `predict()`. Menghitung rata-rata dari keseluruhan dataset sebelum split berisiko menimbulkan **data leakage**.

## 4. Common Mistakes

- Menghitung normalisasi di seluruh dataset sebelum split.
- Menggunakan `fit_transform` pada test data.
- Memakai encoder berbeda saat training dan inference.
- Mengubah urutan kolom input tanpa penanganan yang benar.
