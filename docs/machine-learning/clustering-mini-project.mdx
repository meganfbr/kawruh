# Clustering Mini Project

**Level:** Intermediate | **Prasyarat:** Python, pandas, dasar Machine Learning

## Project Brief

**Tujuan:** mengelompokkan dataset sintetis dua dimensi tanpa label pada proses clustering, lalu menilai hasil menggunakan Silhouette Score.

**Tools:** Colab/Jupyter dan scikit-learn. Dataset dibuat langsung melalui `make_blobs` sehingga tidak memerlukan unduhan.

## 1. Workflow Project

1. Buat data numerik sintetis.
2. Standardisasi fitur.
3. Uji nilai `k` antara 2 sampai 6.
4. Bandingkan silhouette score.
5. Pilih `k` terbaik berdasarkan skor, kemudian visualisasikan cluster.

## 2. Notebook Lengkap — Colab/Jupyter

```python
import matplotlib.pyplot as plt
from sklearn.datasets import make_blobs
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score

X, _ = make_blobs(n_samples=240, centers=3, cluster_std=0.75, random_state=42)
X_scaled = StandardScaler().fit_transform(X)
results = {}
for k in range(2, 7):
    model = KMeans(n_clusters=k, random_state=42, n_init=10)
    labels = model.fit_predict(X_scaled)
    results[k] = silhouette_score(X_scaled, labels)

best_k = max(results, key=results.get)
final_model = KMeans(n_clusters=best_k, random_state=42, n_init=10)
labels = final_model.fit_predict(X_scaled)
print('Silhouette by k:', results)
print('Selected k:', best_k)

plt.scatter(X_scaled[:, 0], X_scaled[:, 1], c=labels, cmap='viridis', s=24)
plt.scatter(final_model.cluster_centers_[:, 0], final_model.cluster_centers_[:, 1],
            marker='X', s=200, c='red', label='Centroid')
plt.title('K-Means on Synthetic Dataset')
plt.legend()
plt.show()
```

**Catatan:** Memilih `k` berdasarkan Silhouette Score pada data yang sama merupakan eksplorasi, bukan bukti performa out-of-sample. Skor dan jumlah cluster optimal harus dilaporkan setelah kode dijalankan.
