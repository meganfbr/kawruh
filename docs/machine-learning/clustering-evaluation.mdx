# Clustering Evaluation

**Level:** Beginner–Intermediate | **Course:** Machine Learning


Clustering merupakan metode unsupervised; sering kali kita tidak punya label *ground truth*. Karena itu, evaluasi dapat memakai ukuran internal seperti **silhouette score**, inertia, dan Davies–Bouldin index. Tidak ada satu metrik yang selalu paling baik untuk semua bentuk data.

## Tujuan Pembelajaran

- Memahami perbedaan metrik internal dan eksternal.
- Menafsirkan silhouette score dan inertia dengan benar.
- Memilih jumlah cluster dengan memperhatikan tujuan dan bentuk data.

## 1. Visualisasi Silhouette Score

![Silhouette score berbagai jumlah cluster pada data simulasi](/img/machine-learning/clustering-evaluation.png)

*Gambar: silhouette score untuk k=2 sampai 7 pada dataset simulasi yang memiliki tiga pusat. Grafik tidak membuktikan jumlah cluster optimal untuk dataset lain.*

Silhouette score membandingkan seberapa dekat sampel terhadap cluster sendiri dengan cluster tetangga terdekat. Nilai rata-rata sering berada dalam rentang **-1 sampai 1**: makin mendekati 1 biasanya menunjukkan pemisahan lebih baik; mendekati 0 bisa berarti cluster tumpang tindih. Skor ini umumnya membutuhkan setidaknya 2 cluster dan kurang dari jumlah sampel label yang berbeda.

## 2. Metrik yang Sering Dipakai

| Metrik | Interpretasi dasar | Perhatian |
| --- | --- | --- |
| Silhouette Score | Lebih tinggi umumnya lebih baik | Cenderung menyukai cluster kompak dan terpisah |
| Inertia (K-Means) | Lebih kecil untuk k tertentu | Turun saat k naik; jangan memilih k hanya dari minimum |
| Davies–Bouldin Index | Lebih rendah umumnya lebih baik | Sensitif terhadap bentuk/pemisahan cluster |
| Adjusted Rand Index | Kesesuaian dengan label referensi | Membutuhkan label ground truth |

## 4. Praktik scikit-learn (Colab/Jupyter)

```python
from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score, davies_bouldin_score
from sklearn.preprocessing import StandardScaler

X, _ = make_blobs(n_samples=150, centers=3, random_state=42)
X = StandardScaler().fit_transform(X)
for k in range(2, 6):
    model = KMeans(n_clusters=k, random_state=42, n_init=10)
    labels = model.fit_predict(X)
    print(k, round(silhouette_score(X, labels), 3),
          round(davies_bouldin_score(X, labels), 3))
```

Coba bandingkan beberapa `k`, lalu visualisasikan hasilnya. Periksa juga apakah kelompok yang terbentuk masuk akal untuk masalah yang sedang diteliti.

## 5. Common Mistakes

- Memakai accuracy biasa terhadap nomor label cluster. ID cluster bersifat arbitrer; label `0` belum tentu cocok dengan kelas `0`.
- Menganggap silhouette tertinggi selalu berarti model terbaik bagi kebutuhan bisnis.
- Membandingkan inertia dua dataset atau skala yang berbeda secara langsung.
- Menghitung silhouette saat semua sampel masuk satu cluster saja.
