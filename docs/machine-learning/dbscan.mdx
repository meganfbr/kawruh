# DBSCAN

**Level:** Beginner–Intermediate | **Course:** Machine Learning


**DBSCAN** (*Density-Based Spatial Clustering of Applications with Noise*) membentuk kelompok berdasarkan kepadatan titik. Algoritma ini dapat menemukan pola berbentuk melengkung dan memberi label `-1` untuk sampel yang tidak masuk cluster.

## Tujuan Pembelajaran

- Mengerti konsep tetangga, core point, border point, dan noise.
- Menguji pengaruh `eps` dan `min_samples`.
- Membandingkan DBSCAN dengan K-Means.

## 1. Intuisi Visual

![DBSCAN menunjukkan kelompok melengkung dan titik noise](/img/machine-learning/dbscan-density.png)

*Gambar: hasil DBSCAN pada dataset simulasi dua bulan sabit dengan tambahan titik acak; tanda silang menandai noise.*

`eps` adalah radius lingkungan yang digunakan dalam perhitungan ketetanggaan. `min_samples` adalah jumlah minimum sampel (termasuk titik itu sendiri dalam implementasi scikit-learn) agar suatu sampel dianggap *core point*.

Ini hanya perhitungan tetangga satu dimensi agar konsep mudah dipahami; algoritma DBSCAN aslinya melakukan pencarian ketetanggaan pada seluruh sampel.

## 3. Praktik DBSCAN dengan scikit-learn (Colab/Jupyter)

```python
from sklearn.datasets import make_moons
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import DBSCAN

X, _ = make_moons(n_samples=300, noise=0.06, random_state=42)
X_scaled = StandardScaler().fit_transform(X)
model = DBSCAN(eps=0.3, min_samples=5)
labels = model.fit_predict(X_scaled)
print("Cluster tanpa noise:", len(set(labels) - {-1}))
print("Jumlah noise:", (labels == -1).sum())
```

`eps` bergantung pada skala fitur. Coba beberapa nilai dan periksa jumlah cluster serta sampel noise.

## 4. Kelebihan dan Keterbatasan

| Kelebihan | Keterbatasan |
| --- | --- |
| Tidak meminta jumlah cluster di awal | Sensitif terhadap `eps` dan `min_samples` |
| Dapat menemukan bentuk cluster tidak bulat | Sulit pada kelompok dengan kepadatan sangat berbeda |
| Memberi penanda noise | Jarak kurang informatif pada dimensi sangat tinggi |
