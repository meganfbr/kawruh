# Cross Validation

**Level:** Intermediate | **Prasyarat:** Python, pandas, dasar Machine Learning

## Learning Objectives

Setelah materi ini, kamu bisa menjelaskan alasan cross validation, perbedaan dengan test set, cara memakai `cross_val_score`, dan bahaya data leakage.

## 1. Mengapa Satu Pembagian Data Tidak Selalu Cukup?

Skor model dapat berubah tergantung sampel yang masuk ke train dan validation. **K-Fold Cross Validation** membagi data pengembangan menjadi K bagian (fold), lalu melatih K kali: satu fold untuk validasi dan sisanya untuk pelatihan.

![Ilustrasi pembagian fold](/img/machine-learning/cross-validation-folds.png)

*Gambar: setiap baris merupakan satu putaran; fold validasi berganti, sedangkan fold lain menjadi data latih.*

## 2. Bagaimana Menghitung Rata-Ratanya?

Misalnya skor validasi lima fold adalah `0.80`, `0.84`, `0.78`, `0.86`, dan `0.82`. Skor rata-ratanya dihitung dari seluruh fold.

## 3. Contoh scikit-learn di Google Colab

Kode berikut memerlukan `scikit-learn`. Jalankan di Colab/Jupyter, bukan di Playground browser Kawruh.

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import StratifiedKFold, cross_val_score
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression

X, y = load_iris(return_X_y=True)
model = make_pipeline(StandardScaler(), LogisticRegression(max_iter=1000))
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
scores = cross_val_score(model, X, y, cv=cv, scoring='accuracy')
print('Skor per fold:', scores)
print('Rata-rata:', scores.mean())
```

**Mengapa Pipeline?** `StandardScaler` akan *fit* menggunakan data train pada setiap fold, bukan mempelajari statistik dari seluruh data sebelum validasi.

## 4. Cross Validation Bukan Pengganti Test Set

Gunakan *test set* yang terpisah hanya untuk evaluasi akhir. Pemilihan model, parameter, dan preprocessing dilakukan menggunakan train/validation atau cross validation. Untuk data berdasarkan waktu gunakan `TimeSeriesSplit`, dan untuk beberapa sampel dari subjek yang sama pertimbangkan `GroupKFold` agar tidak terjadi kebocoran antarsubjek.

## 5. Common Mistakes

- Melakukan scaling di seluruh data sebelum membuat fold.
- Memilih hyperparameter berdasarkan hasil test set.
- Menggunakan K-Fold acak pada data deret waktu.
- Menganggap rata-rata cross validation menjamin kinerja pada data baru.
