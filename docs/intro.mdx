# Welcome to Kawruh

Kawruh adalah platform pembelajaran Python,
Data Analytics, Machine Learning, Deep Learning,
dan Artificial Intelligence.

## Apa yang bisa kamu pelajari?

- Python Programming
- Data Analytics dan Data Visualization
- Machine Learning
- Deep Learning
- Dataset Exploration
- AI Research Methodology

## Mulai perjalanan belajarmu

Jika kamu baru belajar pemrograman, mulailah
dengan Python Introduction.

Jika kamu sudah memahami Python, lanjutkan
ke pengolahan data menggunakan NumPy dan Pandas.

:::tip Tips Belajar
Pelajari konsep, coba contoh kode, dan
kerjakan latihan agar lebih memahami materi.
:::

Kawruh — Learn, Explore, Innovate.
