# pandas Introduction

**Level:** Beginner | **Estimasi belajar:** 30–45 menit

Kita mulai dari alasan pandas sangat populer dalam analisis data, lalu membuat tabel sederhana.

## Tujuan Pembelajaran

- Memahami kegunaan pandas untuk mengolah data berbentuk tabel.
- Membuat `DataFrame`, memeriksa kolom, dan mengambil beberapa baris.
- Membedakan contoh pandas yang dijalankan di Colab dari latihan Python murni di Kawruh.

## 1. Mengapa pandas?

**pandas** adalah library Python untuk mengolah data terstruktur seperti tabel nilai, catatan transaksi, dan hasil survei. Dua struktur yang sering dipakai adalah **Series** (satu dimensi) dan **DataFrame** (dua dimensi).

| Istilah | Makna sederhana | Contoh |
| --- | --- | --- |
| Row/baris | Satu catatan | Satu transaksi |
| Column/kolom | Satu atribut | `harga`, `jumlah` |
| DataFrame | Tabel berisi baris dan kolom | Tabel penjualan |
| Series | Satu kolom berlabel indeks | Kolom harga |

## 3. Membuat DataFrame

```python
import pandas as pd

penjualan = pd.DataFrame({
    "produk": ["Buku", "Pulpen", "Tas"],
    "harga": [45000, 5000, 120000],
    "terjual": [3, 10, 2],
})
print(penjualan)
```

**Penjelasan:** `pd.DataFrame()` membentuk tabel; setiap kunci dictionary menjadi nama kolom dan daftar nilainya menjadi baris. Semua daftar pada contoh mempunyai panjang sama.

## 4. Mengenal tabel sebelum menganalisis

```python
print(penjualan.head(2))    # Dua baris pertama
print(penjualan.shape)      # (jumlah baris, jumlah kolom)
print(penjualan.columns)    # Nama-nama kolom
print(penjualan.dtypes)     # Tipe data per kolom
print(penjualan.info())     # Ringkasan struktur dan nilai non-null
```

`info()` sudah menampilkan ringkasan, sehingga tidak harus dibungkus `print()`; contoh tersebut memperlihatkan bahwa hasil kembalian `info()` adalah `None`.

## 6. Studi Kasus — total penjualan dengan pandas

```python
penjualan["total"] = penjualan["harga"] * penjualan["terjual"]
print(penjualan[["produk", "total"]])
print("Omzet:", penjualan["total"].sum())
```

Perkalian antar-Series pada baris tersebut dilakukan **element-wise**, yaitu tiap baris `harga` dikalikan `terjual` pada baris yang sama.

## 7. Common Mistakes

- Menulis `import panda` bukan `import pandas as pd`.
- Menganggap `DataFrame` sama dengan list biasa; keduanya punya kemampuan dan perilaku yang berbeda.
- Memakai nama kolom salah kapitalisasi: `penjualan["Harga"]` berbeda dari `penjualan["harga"]`.
