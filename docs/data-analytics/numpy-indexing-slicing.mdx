# NumPy Indexing And Slicing

**Level:** Beginner | **Prasyarat:** NumPy Arrays | **Estimasi:** 35–45 menit

Indexing digunakan untuk mengambil sebuah elemen; slicing digunakan untuk mengambil rentang elemen dari array. Indeks Python dimulai dari nol.

## Tujuan Pembelajaran

Kamu mampu mengambil elemen 1D dan 2D, menggunakan irisan `start:stop:step`, memakai indeks negatif dan filter Boolean, serta memahami bahwa hasil slice NumPy sering merupakan *view*.

## 1. Indexing Array 1D

```python
import numpy as np

nilai = np.array([60, 70, 80, 90])
print(nilai[0])   # 60
print(nilai[2])   # 80
print(nilai[-1])  # 90
```

Indeks `0` mengakses elemen pertama. Indeks `-1` mengakses elemen terakhir.

## 2. Dasar Slicing

Bentuk umum: `array[start:stop:step]`. Indeks `stop` **tidak ikut diambil**.

```python
import numpy as np

nilai = np.array([10, 20, 30, 40, 50, 60])
print(nilai[1:4])   # 20, 30, 40
print(nilai[:3])    # 10, 20, 30
print(nilai[::2])   # 10, 30, 50
print(nilai[::-1])  # urutan terbalik
```

| Ekspresi | Makna |
| --- | --- |
| `[1:4]` | Dari indeks 1 sampai sebelum 4 |
| `[:3]` | Dari awal sampai sebelum 3 |
| `[3:]` | Dari indeks 3 sampai akhir |
| `[::2]` | Ambil setiap dua elemen |
| `[::-1]` | Balik urutan |

## 3. Indexing Array 2D

```python
import numpy as np

matriks = np.array([
    [10, 20, 30],
    [40, 50, 60],
    [70, 80, 90],
])

print(matriks[1, 2])   # 60
print(matriks[0, :])   # baris pertama
print(matriks[:, 1])   # kolom kedua
print(matriks[0:2, 1:3])
```

Pada `matriks[baris, kolom]`, sumbu pertama menunjuk baris dan sumbu kedua menunjuk kolom. Simbol `:` berarti ambil semua indeks pada sumbu itu.

## 4. Boolean Indexing

Gunakan kondisi untuk memilih data yang memenuhi kriteria.

```python
import numpy as np

nilai = np.array([65, 75, 88, 92])
mask = nilai >= 75
print(mask)
print(nilai[mask])
```

Mask Boolean menghasilkan `True` pada posisi yang lolos. Boolean indexing menghasilkan array berisi nilai terpilih.

## 5. Penting: View vs Copy

Basic slicing NumPy umumnya menghasilkan *view*, yaitu tampilan yang masih berbagi memori dengan array asal.

```python
import numpy as np

nilai = np.array([10, 20, 30, 40])
subset = nilai[1:3]
subset[0] = 999
print(nilai)  # [10 999 30 40]
```

Jika membutuhkan data terpisah, gunakan `.copy()` setelah slicing. Boolean indexing atau fancy indexing umumnya menghasilkan salinan, bukan view biasa.

<Admonition type="warning" title="Hati-hati saat Mengubah Slice">

Mengubah elemen hasil basic slicing bisa mengubah array sumber. Gunakan `.copy()` jika tidak ingin efek samping.

</Admonition>

## 6. Common Mistakes

- Mengambil elemen keempat dengan `[4]` padahal indeksnya `[3]`.
- Mengira batas akhir slicing ikut diambil.
- Menukar urutan baris dan kolom pada array 2D.
- Mengubah slice lalu heran array aslinya ikut berubah.

## 9. Ringkasan

Gunakan indexing untuk sebuah elemen, slicing untuk rentang, `[:, kolom]` untuk satu kolom, serta mask Boolean untuk filtering. Berikutnya kita belajar **NumPy Statistics** untuk merangkum data numerik.
