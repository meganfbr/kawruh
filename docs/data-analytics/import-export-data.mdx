# Importing And Exporting Data

**Level:** Beginner | **Estimasi belajar:** 30–45 menit

Analisis data hampir selalu dimulai dari membaca sumber data dan menyimpan hasilnya dengan benar.

## Tujuan Pembelajaran

- Membaca dan menulis CSV menggunakan pandas.
- Mengenal perbedaan CSV, Excel, dan JSON.
- Memahami path, delimiter, dan encoding dasar.

## 1. Format data yang umum

| Format | Kegunaan | pandas |
| --- | --- | --- |
| CSV | Tabel teks, portabel | `read_csv`, `to_csv` |
| Excel | Spreadsheet multi-sheet | `read_excel`, `to_excel` |
| JSON | Data dengan struktur key-value | `read_json`, `to_json` |

## 2. Import file CSV

Siapkan berkas `penjualan.csv` di folder kerja notebook:

```csv
produk,harga,terjual
Buku,45000,3
Pulpen,5000,10
Tas,120000,2
```

Lalu jalankan di Colab/Jupyter:

```python
import pandas as pd

df = pd.read_csv("penjualan.csv")
print(df.head())
print(df.info())
```

**Penjelasan:** `read_csv()` membaca isi file ke DataFrame; `head()` memberi pratinjau. Pastikan file benar-benar tersedia di lokasi notebook.

## 3. Export CSV

```python
df["total"] = df["harga"] * df["terjual"]
df.to_csv("penjualan_hasil.csv", index=False)
```

`index=False` mencegah indeks DataFrame ditulis sebagai kolom tambahan.

## 4. Excel dan JSON

```python
# Untuk Excel, instal openpyxl jika diperlukan.
df.to_excel("penjualan.xlsx", index=False)

# JSON dalam format records
df.to_json("penjualan.json", orient="records", indent=2)
```

<Admonition type="info" title="Catatan Eksekusi">

Kode file I/O dengan pandas dijalankan di Colab atau Jupyter. Pada Google Colab, file lokal komputer perlu diunggah dahulu atau tersedia melalui penyimpanan yang dipasang.

</Admonition>

## 5. Separator dan masalah umum

```python
# Jika CSV memakai titik koma
pd.read_csv("data-semicolon.csv", sep=";")

# Jika encoding UTF-8
pd.read_csv("penjualan.csv", encoding="utf-8")
```

Kasus yang sering terjadi: file tidak ditemukan (`FileNotFoundError`), delimiter salah sehingga semua data masuk satu kolom, atau angka dibaca sebagai teks karena format angka tidak konsisten.
