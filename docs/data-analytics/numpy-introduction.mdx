# NumPy Introduction

**Level:** Beginner | **Prasyarat:** List, Loops, Environment Setup | **Estimasi:** 30 menit

**NumPy** adalah library Python untuk komputasi numerik. Struktur data utamanya, `ndarray`, memungkinkan operasi terhadap banyak elemen array dengan sintaks yang ringkas.

## Tujuan Pembelajaran

Kamu dapat menjelaskan perbedaan list dan array, membuat array sederhana, membaca `shape` dan `dtype`, serta menghitung statistik dasar.

## 1. Mengapa NumPy?

List bawaan Python berguna untuk berbagai tipe data. NumPy dirancang untuk array numerik yang homogen dan operasi vektorisasi. Namun, NumPy tidak otomatis lebih baik untuk setiap tugas; keunggulannya terasa pada komputasi array numerik yang sesuai.

## 2. Membuat Array

Jalankan contoh berikut di **Google Colab atau Jupyter**, bukan di Python Playground Kawruh untuk saat ini.

```python
import numpy as np

nilai = np.array([80, 85, 90, 95])

print(nilai)
print(nilai.shape)
print(nilai.dtype)
```

### Penjelasan Baris per Baris

| Kode | Penjelasan |
| --- | --- |
| `import numpy as np` | Memberi alias pendek untuk NumPy |
| `np.array([...])` | Mengubah kumpulan nilai menjadi ndarray |
| `.shape` | Menunjukkan ukuran setiap dimensi, contoh `(4,)` |
| `.dtype` | Menunjukkan tipe elemen array; hasil spesifik bergantung lingkungan |

## 3. Operasi Vektorisasi

```python
import numpy as np

nilai = np.array([80, 85, 90, 95])

print(nilai + 5)
print(nilai * 2)
print(nilai.mean())
```

Dengan NumPy, penambahan `5` diterapkan ke setiap elemen. Sebaliknya, `list_python + [5]` akan menambahkan elemen baru ke akhir list, bukan menambahkan lima ke semua elemennya.

## 5. Array Dua Dimensi

```python
import numpy as np

matriks = np.array([
    [1, 2, 3],
    [4, 5, 6],
])

print(matriks.shape)  # (2, 3)
print(matriks[0, 1])  # 2
```

`shape (2, 3)` berarti dua baris dan tiga kolom. NumPy menggunakan indeks berbasis nol.

## 6. Common Mistakes

- Mengira penjumlahan dua list sama dengan penjumlahan dua array.
- Menyamakan `shape` dan `size`: `shape` adalah ukuran per dimensi; `size` jumlah keseluruhan elemen.
- Menganggap `.dtype` selalu `int64`; hasilnya bisa berbeda bergantung platform dan data.
- Melakukan pembagian oleh nol tanpa memeriksa hasil atau peringatan.
