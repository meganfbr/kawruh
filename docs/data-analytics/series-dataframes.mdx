# Series And DataFrames

**Level:** Beginner | **Estimasi belajar:** 30–45 menit

Di materi ini kamu belajar mengambil dan mengolah data dalam bentuk kolom serta baris.

## Tujuan Pembelajaran

- Membedakan `Series` dan `DataFrame`.
- Memilih kolom dan baris menggunakan `[]`, `.loc[]`, dan `.iloc[]`.
- Memahami indeks, tipe data, dan operasi kolom.

## 1. Series: satu dimensi

```python
import pandas as pd

nilai = pd.Series([80, 85, 90], name="nilai")
print(nilai)
print(nilai.mean())
```

Setiap nilai memiliki **indeks**. Secara default, indeksnya dimulai dari `0`, tetapi indeks bisa berupa label lain.

## 2. DataFrame: banyak kolom

```python
import pandas as pd

df = pd.DataFrame({
    "nama": ["Ana", "Budi", "Citra"],
    "nilai": [80, 85, 90],
    "hadir": [True, True, False],
})
print(df)
```

| Ekspresi | Hasil |
| --- | --- |
| `df["nilai"]` | Series satu kolom |
| `df[["nama", "nilai"]]` | DataFrame dua kolom |
| `df.iloc[0]` | Baris pertama berdasarkan posisi |
| `df.loc[0]` | Baris dengan label indeks `0` |
| `df.shape` | Ukuran tabel, misalnya `(3, 3)` |

## 3. Memilih baris dan kolom

```python
print(df.loc[1, "nama"])  # Budi, berdasarkan label
print(df.iloc[1, 1])      # 85, berdasarkan posisi
print(df[df["nilai"] >= 85])  # Filter baris
```

<Admonition type="warning" title="loc vs iloc">

`.loc` menggunakan **label**, sedangkan `.iloc` menggunakan **posisi integer**. Jika indeks sebuah DataFrame telah berubah, hasil keduanya bisa berbeda.

</Admonition>

## 4. Membuat kolom baru

```python
df["lulus"] = df["nilai"] >= 85
print(df[["nama", "nilai", "lulus"]])
```

Pada contoh ini, perbandingan menghasilkan Series boolean untuk setiap baris.

## 6. Kesalahan Umum

- Mengakses `df["nama", "nilai"]` padahal ingin dua kolom. Gunakan `df[["nama", "nilai"]]`.
- Menganggap `df.iloc[1]` sama dengan `df.loc[1]` pada semua indeks.
- Mengubah DataFrame dengan operasi berantai tanpa memahami apakah perubahan tersimpan.

## 9. Ringkasan
