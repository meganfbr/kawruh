# Variables

**Level:** Beginner | **Learning Path:** Python Programming

Memahami variabel, assignment, dan aturan penamaan.

## Tujuan Pembelajaran

Setelah menyelesaikan materi ini, kamu dapat memahami konsepnya, membaca contoh kode, dan mencoba latihan mandiri.

## Konsep Variabel

Nama variabel mengacu ke suatu objek bernilai. Gunakan operator `=` untuk memberi nilai.

```python
nama = "Kawruh"
umur = 20
print(nama, umur)
```

<PythonPlayground initialCode={"nama = \"Kawruh\"\numur = 20\nprint(nama)\nprint(umur)"} />

## Aturan Penamaan

- Gunakan huruf, digit, dan underscore; tidak boleh dimulai digit.
- Hindari spasi dan keyword seperti `class` atau `for`.
- `nama` berbeda dengan `Nama`.
- Gunakan `snake_case` agar kode lebih terbaca.

## Mengubah Nilai

```python
nilai = 80
nilai = 95
print(nilai)
```

**Output:** `95`.

## Penjelasan Kode

| Baris | Arti |
| --- | --- |
| `nilai = 80` | Nama `nilai` mengacu ke integer 80 |
| `nilai = 95` | Nama tersebut sekarang mengacu ke 95 |
| `print(nilai)` | Mencetak nilai terakhir |

## Kesalahan Umum

`print(Nama)` menghasilkan `NameError` jika yang didefinisikan hanya `nama`.
