# Conditions

**Level:** Beginner | **Learning Path:** Python Programming

Mengatur percabangan program dengan if, elif, dan else.

## Tujuan Pembelajaran

Setelah menyelesaikan materi ini, kamu dapat memahami konsepnya, membaca contoh kode, dan mencoba latihan mandiri.

## Percabangan

Python menjalankan blok `if` jika kondisi truthy. Gunakan `elif` untuk kondisi tambahan dan `else` untuk kondisi lain.

```python
nilai = 80
if nilai >= 75:
    print("Lulus")
else:
    print("Belum lulus")
```
