# Data Types

**Level:** Beginner | **Learning Path:** Python Programming

Memahami jenis nilai Python dan cara mengonversinya.

## Tujuan Pembelajaran

Setelah menyelesaikan materi ini, kamu dapat memahami konsepnya, membaca contoh kode, dan mencoba latihan mandiri.

## Tipe Data Umum

| Jenis | Contoh | Keterangan |
| --- | --- | --- |
| `str` | `"data"` | Teks |
| `int` | `12` | Bilangan bulat |
| `float` | `3.5` | Bilangan desimal |
| `bool` | `True` | Nilai logika |
| `list` | `[1, 2]` | Koleksi berurutan dan bisa diubah |
| `tuple` | `(1, 2)` | Koleksi berurutan, tidak bisa diubah elemennya |
| `set` | `{1, 2}` | Himpunan unik |
| `dict` | `{"a": 1}` | Pasangan key-value |
| `NoneType` | `None` | Nilai ketiadaan |

## Konversi Tipe

```python
umur_teks = "21"
umur = int(umur_teks)
print(umur + 1)
```

**Output:** `22`.

Konversi tidak selalu berhasil: `int("dua")` akan memunculkan `ValueError`.

## Hubungan dengan Data Science

Saat mengimpor CSV, periksa apakah kolom angka terbaca sebagai string; tipe yang salah dapat mengganggu operasi statistik.
