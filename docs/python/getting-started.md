# Persiapan Belajar Python

Selamat datang di Python Learning Path Kawruh.

Sebelum mulai menulis kode, kamu perlu memahami perangkat,
software, dan lingkungan pemrograman yang akan digunakan.

## 1. Apa yang dibutuhkan?

Untuk mempelajari Python dasar, kamu tidak memerlukan
laptop gaming atau GPU khusus.

Perangkat yang disarankan:

| Komponen  | Panduan Awal                                  |
| --------- | --------------------------------------------- |
| Processor | CPU modern yang mampu menjalankan Python      |
| RAM       | 4 GB untuk latihan ringan, 8 GB lebih nyaman  |
| Storage   | Sediakan beberapa GB ruang kosong             |
| GPU       | Tidak wajib untuk Python dasar                |
| Internet  | Dibutuhkan untuk instalasi dan notebook cloud |

Angka tersebut merupakan panduan praktis, bukan
spesifikasi minimum resmi Python.

## 2. Pilih tools pemrograman

### Python

Python adalah bahasa pemrograman yang akan dipelajari.

Website resmi:
https://www.python.org/

### Visual Studio Code

VS Code merupakan code editor untuk menulis,
menjalankan, dan mengelola project Python.

Website resmi:
https://code.visualstudio.com/

### Google Colab

Google Colab adalah lingkungan notebook berbasis cloud.

Kamu dapat menggunakan Colab tanpa perlu memasang
Python secara lokal.

Website resmi:
https://colab.research.google.com/

### Jupyter Notebook

Jupyter menyediakan lingkungan interaktif untuk
menjalankan kode, teks, serta visualisasi data.

Website resmi:
https://jupyter.org/

## 3. Extensions VS Code

pada Visual Studio Code.

## 4. Apa itu Python library?

Library merupakan kumpulan fungsi atau modul yang
membantu kita menyelesaikan pekerjaan tertentu.

Contohnya:

- NumPy untuk komputasi numerik.
- pandas untuk mengolah data tabular.
- Matplotlib untuk visualisasi data.
- scikit-learn untuk machine learning.
- PyTorch untuk deep learning.

Kamu tidak perlu memasang semua library di awal.

## 5. Memilih lingkungan belajar

Jika laptop memiliki RAM terbatas, Google Colab
atau playground browser dapat menjadi alternatif
untuk latihan sederhana.

Untuk model deep learning besar, kebutuhan hardware
bergantung pada model, dataset, batch size,
dan konfigurasi training.
