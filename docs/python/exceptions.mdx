# Exceptions

**Level:** Intermediate | **Learning Path:** Python Programming

Menangani kesalahan runtime dengan try dan except.

## Tujuan Pembelajaran

Setelah menyelesaikan materi ini, kamu dapat memahami konsepnya, membaca contoh kode, dan mencoba latihan mandiri.

## Apa Itu Exception?

Exception memberi tahu bahwa operasi gagal, seperti membagi dengan nol atau mengonversi string yang bukan angka.

## Try / Except

<PythonPlayground initialCode={"teks = \"dua\"\ntry:\n    angka = int(teks)\nexcept ValueError:\n    print(\"Masukkan angka yang valid\")"} />

## Else dan Finally

`else` dijalankan jika blok `try` tidak menghasilkan exception; `finally` dijalankan saat keluar dari struktur try, termasuk pada umumnya ketika terjadi exception.

## Praktik Baik

Tangani exception spesifik (`ValueError`, `KeyError`) daripada menangkap semua error tanpa alasan.
