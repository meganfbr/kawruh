# Lists

**Level:** Beginner | **Learning Path:** Python Programming

Mengolah kumpulan data berurutan yang dapat dimodifikasi.

## Tujuan Pembelajaran

Setelah menyelesaikan materi ini, kamu dapat memahami konsepnya, membaca contoh kode, dan mencoba latihan mandiri.

## Membuat List

List mempertahankan urutan dan mendukung elemen berulang.

```python
nilai = [80, 85, 90]
```

## Index, Slicing, dan Append

<PythonPlayground initialCode={"nilai = [80, 85, 90]\nprint(nilai[0])\nnilai.append(95)\nprint(nilai)\nprint(nilai[1:3])"} />

## Mengubah dan Menghapus

Gunakan `nilai[0] = 100`, `remove`, atau `pop` sesuai kebutuhan. `len` menghitung banyak elemen.

## Hubungan dengan Dataset

List cocok untuk menyimpan nilai sementara; untuk analisis tabular berskala lebih besar, gunakan pandas sesuai jenis datanya.
