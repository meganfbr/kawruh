# Input And Output

**Level:** Beginner | **Learning Path:** Python Programming

Memahami print, format output, dan input pengguna.

## Tujuan Pembelajaran

Setelah menyelesaikan materi ini, kamu dapat memahami konsepnya, membaca contoh kode, dan mencoba latihan mandiri.

## Menampilkan Output

Gunakan `print()` dan f-string untuk menampilkan informasi yang mudah dibaca.

```python
nama = "Ayu"
print(f"Halo, {nama}")
```

## Membaca Input

Pada Python lokal, `input()` membaca teks dari terminal:

```python
# Cocok dicoba di terminal lokal
nama = input("Nama: ")
print(nama)
```

**Catatan:** Python Playground Kawruh belum menyediakan input interaktif, sehingga contoh `input()` di atas jangan dijalankan di sana sampai fiturnya ditambahkan.
