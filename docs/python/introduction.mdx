# Python Introduction

**Level:** Beginner | **Learning Path:** Python Programming

Mengenal bahasa Python, sintaks dasar, dan program pertama.

## Tujuan Pembelajaran

Setelah menyelesaikan materi ini, kamu dapat memahami konsepnya, membaca contoh kode, dan mencoba latihan mandiri.

## Apa Itu Python?

Python adalah bahasa pemrograman serbaguna yang populer untuk otomasi, aplikasi, analisis data, machine learning, dan AI. Sintaksnya menggunakan indentasi untuk menunjukkan blok kode.

## Program Pertama

```python
print("Hello, Kawruh!")
```

**Output yang diharapkan:**

```text
Hello, Kawruh!
```

<PythonPlayground initialCode={"print(\"Hello, Kawruh!\")\nprint(10 + 5)"} />

## Penjelasan Per Baris

| Kode | Arti |
| --- | --- |
| `print("Hello, Kawruh!")` | Memanggil fungsi bawaan `print()` untuk menampilkan teks |
| `print(10 + 5)` | Menghitung penjumlahan dan menampilkannya |

## Komentar

Baris yang diawali `#` dipakai sebagai komentar dan tidak dieksekusi.

```python
# Ini komentar
print("Saya belajar Python")
```

## Kesalahan Umum

Perhatikan kurung tutup, tanda kutip, dan perbedaan kapital pada nama variabel.
