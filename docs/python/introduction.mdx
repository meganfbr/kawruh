# Python Introduction

Python adalah bahasa pemrograman tingkat tinggi yang banyak digunakan dalam pengembangan software, analisis data, machine learning, dan artificial intelligence.

Pada materi ini, kamu akan mengenal Python dan mencoba menjalankan kode pertamamu secara langsung di Kawruh.

## Apa itu Python?

Python merupakan bahasa pemrograman yang memiliki sintaks relatif sederhana dan mudah dibaca.

Python dapat digunakan untuk berbagai kebutuhan, seperti:

- Web Development
- Data Analytics
- Machine Learning
- Deep Learning
- Automation
- Artificial Intelligence

## Mengapa Belajar Python?

Python populer karena:

- Sintaksnya relatif mudah dipahami.
- Mendukung berbagai paradigma pemrograman.
- Memiliki ekosistem library yang luas.
- Banyak digunakan dalam Data Science dan AI.
- Memiliki komunitas pengembang yang besar.

## Contoh Kode Python

Salah satu fungsi dasar Python adalah `print()`.

Fungsi ini digunakan untuk menampilkan teks atau nilai ke layar.

Contohnya:

```python
print("Hello, Kawruh!")
```

**Output:**

```text
Hello, Kawruh!
```

## Penjelasan Kode

Mari kita pahami kode sebelumnya.

### 1. Fungsi print()

```python
print("Hello, Kawruh!")
```

- `print()` adalah fungsi bawaan Python.
- Teks di dalam tanda kutip disebut string.
- Python akan menampilkan string tersebut sebagai output.

### 2. Operasi Aritmatika

```python
print(10 + 5)
```

- `10` dan `5` merupakan nilai integer.
- Simbol `+` adalah operator penjumlahan.
- Python menghitung hasil penjumlahan sebelum menampilkannya.

**Output:**

```text
15
```
