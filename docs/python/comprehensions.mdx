# Comprehensions

**Level:** Intermediate | **Learning Path:** Python Programming

Menulis list dan dictionary comprehension yang mudah dibaca.

## Tujuan Pembelajaran

Setelah menyelesaikan materi ini, kamu dapat memahami konsepnya, membaca contoh kode, dan mencoba latihan mandiri.

## List Comprehension

Comprehension mengubah iterable menjadi koleksi baru secara ringkas.

```python
kuadrat = [x ** 2 for x in range(5)]
```

## Filter dalam Comprehension

<PythonPlayground initialCode={"angka = [1, 2, 3, 4, 5, 6]\ngenap = [n for n in angka if n % 2 == 0]\nprint(genap)"} />

## Dictionary Comprehension

```python
kuadrat = {n: n ** 2 for n in range(3)}
```

Utamakan kejelasan. Jika expression terlalu rumit, gunakan loop biasa.
