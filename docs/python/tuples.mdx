# Tuples

**Level:** Beginner | **Learning Path:** Python Programming

Membuat dan membaca koleksi tuple yang immutable.

## Tujuan Pembelajaran

Setelah menyelesaikan materi ini, kamu dapat memahami konsepnya, membaca contoh kode, dan mencoba latihan mandiri.

## Tuple

Tuple adalah koleksi berurutan; elemennya tidak dapat diganti lewat assignment indeks.

```python
posisi = (10, 20)
print(posisi[0])
```

## Unpacking

<PythonPlayground initialCode={"koordinat = (7, 12)\nx, y = koordinat\nprint(x)\nprint(y)"} />

## Tuple Satu Elemen

Gunakan koma: `item = (5,)`. Tanpa koma, `(5)` hanyalah integer yang diberi tanda kurung.

## Kapan Digunakan?

Tuple berguna untuk pasangan koordinat, nilai return beberapa item, dan struktur berukuran tetap.
