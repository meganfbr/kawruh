# Strings

**Level:** Beginner | **Learning Path:** Python Programming

Mengolah teks dengan indexing, slicing, dan method string.

## Tujuan Pembelajaran

Setelah menyelesaikan materi ini, kamu dapat memahami konsepnya, membaca contoh kode, dan mencoba latihan mandiri.

## String dan Index

String adalah urutan karakter. Indeks dimulai dari nol; indeks negatif dihitung dari belakang.

```python
kata = "Kawruh"
print(kata[0])
print(kata[-1])
```

## Slicing dan Method

`teks[start:stop]` mengambil karakter hingga sebelum posisi `stop`.

<PythonPlayground initialCode={"kata = \"Kawruh Python\"\nprint(kata[:6])\nprint(kata.upper())\nprint(kata.lower())\nprint(kata.replace(\"Python\", \"AI\"))"} />

## f-string

```python
nama = "Ayu"
nilai = 90
print(f"{nama} memperoleh nilai {nilai}")
```

## Membersihkan String

`strip()` menghapus whitespace tepi, `split()` memecah menjadi bagian, dan `join()` menggabungkan iterable string.
