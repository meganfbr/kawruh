# Python For Data Science

**Level:** Intermediate | **Learning Path:** Python Programming

Menyiapkan alur belajar menuju NumPy, pandas, dan Machine Learning.

## Tujuan Pembelajaran

Setelah menyelesaikan materi ini, kamu dapat memahami konsepnya, membaca contoh kode, dan mencoba latihan mandiri.

## Setelah Python Dasar

Kini kamu dapat melanjutkan ke workflow Data Science: mengambil data, membersihkan, memvisualisasikan, membangun model sederhana, dan mengevaluasi hasil.

## Library yang Sering Dipakai

| Library | Kegunaan |
| --- | --- |
| NumPy | Array dan operasi numerik |
| pandas | DataFrame dan preprocessing tabular |
| Matplotlib | Grafik |
| scikit-learn | ML klasik, preprocessing, evaluasi |
| PyTorch / TensorFlow | Deep Learning |
| librosa | Analisis audio |
| OpenCV / Pillow | Pengolahan citra |

## Memilih Notebook

- **Colab:** praktis untuk notebook cloud, runtime bergantung ketersediaan.
- **Kaggle:** cocok untuk eksperimen dengan dataset yang di-host di Kaggle.
- **Jupyter lokal:** kontrol environment dan file ada di mesin sendiri.

## Checklist Penelitian

1. Periksa sumber dan lisensi dataset.
2. Pastikan pembagian train/validation/test benar.
3. Hindari kebocoran data (data leakage).
4. Tentukan baseline dan metrik sesuai tujuan.
5. Dokumentasikan preprocessing, seed, dan hasil eksperimen.

## Lanjut Belajar

Buka **Data Analytics**, lalu **Machine Learning** dan **Deep Learning** melalui roadmap Kawruh ketika kontennya sudah tersedia.
