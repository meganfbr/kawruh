# Dictionaries

**Level:** Beginner | **Learning Path:** Python Programming

Menyimpan data berstruktur key-value dengan dictionary.

## Tujuan Pembelajaran

Setelah menyelesaikan materi ini, kamu dapat memahami konsepnya, membaca contoh kode, dan mencoba latihan mandiri.

## Dictionary

Dictionary menghubungkan key dengan value. Key harus hashable dan unik dalam satu dictionary.

```python
mahasiswa = {"nama": "Ayu", "nilai": 90}
print(mahasiswa["nama"])
```

## Membaca dan Mengubah

<PythonPlayground initialCode={"mahasiswa = {\"nama\": \"Ayu\", \"nilai\": 90}\nprint(mahasiswa.get(\"jurusan\", \"Belum diisi\"))\nmahasiswa[\"nilai\"] = 95\nfor k, v in mahasiswa.items():\n    print(k, v)"} />

## Dictionary dalam Data Science

Satu record data dapat direpresentasikan sebagai dictionary, misalnya metadata gambar atau konfigurasi pelatihan.
