# Booleans

**Level:** Beginner | **Learning Path:** Python Programming

Memahami ekspresi benar-salah dan truthiness.

## Tujuan Pembelajaran

Setelah menyelesaikan materi ini, kamu dapat memahami konsepnya, membaca contoh kode, dan mencoba latihan mandiri.

## Nilai Boolean

Nilai `True` dan `False` sering muncul dari perbandingan.

```python
print(10 > 5)
print(10 == 5)
```

## Truthiness

Python menganggap beberapa nilai sebagai false pada kondisi, contohnya `0`, `""`, `[]`, dan `None`. String `"False"` tetap truthy karena tidak kosong.

<PythonPlayground initialCode={"nilai = 82\nlulus = nilai >= 75\nprint(lulus)\nprint(bool(\"\"))\nprint(bool(\"False\"))"} />

## Kombinasi Kondisi

Gunakan `and`, `or`, dan `not` sesuai maksud aturan bisnis atau filter data.
