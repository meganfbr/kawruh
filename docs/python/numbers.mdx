# Numbers

**Level:** Beginner | **Learning Path:** Python Programming

Memahami operasi numerik, pembulatan, dan akurasi float.

## Tujuan Pembelajaran

Setelah menyelesaikan materi ini, kamu dapat memahami konsepnya, membaca contoh kode, dan mencoba latihan mandiri.

## Bilangan di Python

`int` menyimpan bilangan bulat; `float` menyimpan bilangan floating-point; `complex` menyimpan bilangan kompleks.

## Pembulatan dan Nilai Absolut

<PythonPlayground initialCode={"x = -7.25\nprint(abs(x))\nprint(round(3.14159, 2))\nprint(divmod(17, 5))"} />

## Ketelitian Floating-Point

Banyak pecahan desimal tidak dapat direpresentasikan secara eksak dalam bentuk biner.

```python
print(0.1 + 0.2)
```

Jangan mengandalkan kesamaan persis pada hasil desimal untuk semua perhitungan; gunakan `math.isclose` untuk perbandingan toleransi.

## Library Math

```python
import math
print(math.sqrt(81))
```
