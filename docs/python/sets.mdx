# Sets

**Level:** Beginner | **Learning Path:** Python Programming

Mengelola himpunan nilai unik menggunakan set.

## Tujuan Pembelajaran

Setelah menyelesaikan materi ini, kamu dapat memahami konsepnya, membaca contoh kode, dan mencoba latihan mandiri.

## Set dan Elemen Unik

Set menghapus duplikasi dan tidak menyediakan indeks posisi.

```python
kelas = {"A", "B", "A"}
print(len(kelas))
```

## Operasi Himpunan

<PythonPlayground initialCode={"a = {1, 2, 3}\nb = {3, 4}\nprint(sorted(a | b))\nprint(sorted(a & b))\nprint(sorted(a - b))"} />

`|` berarti union, `&` intersection, dan `-` difference. Contoh memakai `sorted()` agar output terurut saat ditampilkan.

## Set Kosong

Gunakan `set()`, bukan `{}`, karena `{}` membuat dictionary kosong.
