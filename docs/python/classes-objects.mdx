# Classes And Objects

**Level:** Intermediate | **Learning Path:** Python Programming

Pengenalan class, object, atribut, dan method.

## Tujuan Pembelajaran

Setelah menyelesaikan materi ini, kamu dapat memahami konsepnya, membaca contoh kode, dan mencoba latihan mandiri.

## Apa Itu Class?

Class adalah cetak biru untuk membuat objek. Objek menyimpan state lewat atribut dan menyediakan perilaku lewat method.

## Contoh Kelas

<PythonPlayground initialCode={"class Mahasiswa:\n    def __init__(self, nama):\n        self.nama = nama\n\n    def sapa(self):\n        return f\"Halo, saya {self.nama}\"\n\nobjek = Mahasiswa(\"Ayu\")\nprint(objek.sapa())"} />

## Penjelasan

| Sintaks | Fungsi |
| --- | --- |
| `class` | Mendefinisikan kelas |
| `__init__` | Menginisialisasi objek baru |
| `self` | Merujuk pada instance saat method dipanggil |
| `self.nama` | Menyimpan atribut instance |

## Relevansi ML

Library seperti scikit-learn sering menyediakan objek model dengan method `fit()` dan `predict()`.
