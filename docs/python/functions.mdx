# Functions

**Level:** Beginner | **Learning Path:** Python Programming

Membuat fungsi reusable dengan parameter dan return.

## Tujuan Pembelajaran

Setelah menyelesaikan materi ini, kamu dapat memahami konsepnya, membaca contoh kode, dan mencoba latihan mandiri.

## Membuat Fungsi

Fungsi didefinisikan dengan `def` dan dapat menerima parameter.

```python
def sapa(nama):
    return "Halo, " + nama
```

## Parameter dan Return

<PythonPlayground initialCode={"def rata_rata(a, b):\n    return (a + b) / 2\n\nprint(rata_rata(80, 90))"} />

`return` mengembalikan nilai kepada pemanggil; `print` hanya menampilkan nilai.

## Default Parameter

```python
def sapa(nama="Teman"):
    return f"Halo, {nama}"
```

## Scope

Variabel lokal di dalam fungsi tidak otomatis tersedia di luar fungsi. Hindari memakai mutable default argument seperti `daftar=[]` tanpa memahami konsekuensinya.
