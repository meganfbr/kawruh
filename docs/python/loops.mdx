# Loops

**Level:** Beginner | **Learning Path:** Python Programming

Mengulang pekerjaan menggunakan for, while, dan range.

## Tujuan Pembelajaran

Setelah menyelesaikan materi ini, kamu dapat memahami konsepnya, membaca contoh kode, dan mencoba latihan mandiri.

## For Loop

Gunakan `for` untuk mengambil elemen dari iterable satu per satu.

```python
for angka in range(3):
    print(angka)
```

**Output:** 0, 1, 2 pada baris terpisah.

## While Loop

`while` mengulang selama kondisi masih true. Pastikan kondisi akhirnya dapat berhenti.

<PythonPlayground initialCode={"total = 0\nfor angka in [1, 2, 3, 4]:\n    total += angka\nprint(total)"} />

## Break dan Continue

`break` menghentikan loop; `continue` melewati sisa iterasi saat ini.

## Hindari Infinite Loop

Jangan menjalankan `while True` tanpa kondisi berhenti di playground.
