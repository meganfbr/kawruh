# Modules

**Level:** Intermediate | **Learning Path:** Python Programming

Mengimpor modul Python dan memahami struktur package.

## Tujuan Pembelajaran

Setelah menyelesaikan materi ini, kamu dapat memahami konsepnya, membaca contoh kode, dan mencoba latihan mandiri.

## Apa Itu Module?

Module adalah berkas Python yang berisi fungsi, kelas, atau variabel. Import membantu menggunakan kembali kode.

```python
import math
print(math.sqrt(16))
```

## Bentuk Import

```python
from statistics import mean
print(mean([80, 90, 100]))
```

<PythonPlayground initialCode={"import math\nfrom statistics import mean\nprint(math.pi)\nprint(mean([10, 20, 30]))"} />

## Pahami Namespace

`math.sqrt` menjelaskan asal fungsi dengan jelas. Hindari `from module import *` pada project besar.

## Library untuk Data Science

Perkenalan: NumPy, pandas, Matplotlib, scikit-learn, TensorFlow, dan PyTorch. Instal hanya yang dibutuhkan sesuai environment.
