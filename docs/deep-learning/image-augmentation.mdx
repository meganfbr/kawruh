# Image Augmentation

**Level:** Beginner–Intermediate | **Prasyarat:** Python, NumPy, dan dasar neural network.

## Tujuan Belajar

Membedakan augmentasi dari preprocessing, memilih transformasi yang sesuai, dan menghindari transformasi yang mengubah makna label.

## 1. Apa itu data augmentation?

Augmentation menghasilkan variasi pelatihan dari contoh yang sama, misalnya flip, rotation, translation, zoom, atau perubahan brightness. Tujuannya mengurangi ketergantungan model terhadap posisi dan kondisi tertentu, **bukan menambah data independen baru**.

![Augmentation](/img/deep-learning/image-augmentation.png)

*Gambar 1. Contoh perubahan orientasi pada ilustrasi sintetis; kesesuaian transformasi tergantung tugas.*

## 2. Contoh dengan Keras (Colab)

```python
import tensorflow as tf

augmentation = tf.keras.Sequential([
    tf.keras.layers.RandomFlip('horizontal'),
    tf.keras.layers.RandomRotation(0.05),
    tf.keras.layers.RandomZoom(0.1),
])

# Jalankan hanya dalam jalur training, bukan validation/test.
```

### Memilih augmentasi yang masuk akal

| Tugas | Augmentasi | Hal yang perlu diperhatikan |
| --- | --- | --- |
| Foto objek umum | Flip, crop, zoom | Label kelas harus tetap benar |
| X-ray medis | Rotasi kecil, kontras terbatas | Orientasi/laterality bisa bermakna |
| OCR karakter | Rotasi kecil | Flip dapat mengubah arti karakter |
| Semantic segmentation | Transformasi geometri sinkron | Mask harus mengalami transformasi yang sama |

## 3. Common Mistakes

- Menggunakan transformasi acak ke dataset test.
- Mengubah gambar tetapi tidak mengubah *bounding box* atau mask saat tugas membutuhkan anotasi spasial.
- Mengasumsikan semua flip aman untuk semua dataset.
