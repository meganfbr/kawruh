## 2. Apa Itu Backpropagation?

Backpropagation menghitung **gradien loss terhadap parameter** menggunakan *chain rule* (aturan rantai) dari kalkulus. Gradien ini dipakai optimizer untuk memperbarui weight dan bias.

## 3. Forward dan Backward Pass

**Forward pass:** hitung output lalu loss. **Backward pass:** hitung turunan loss, dari layer terakhir menuju layer awal. **Optimizer step:** gunakan gradien untuk memperbarui parameter.

## 4. Intuisi Chain Rule

Jika `z = wx` dan `L = (z - target)^2`, maka `dL/dw = 2*(z-target)*x`. Ini contoh satu parameter yang sangat sederhana; library deep learning menerapkan automatic differentiation untuk graf komputasi yang lebih rumit.

## 5. Contoh Pembaruan Gradient Descent

`w_baru = w_lama - learning_rate * gradien`. Jika gradien positif, weight akan bergerak ke arah nilai lebih kecil untuk langkah kecil; jika negatif, weight akan meningkat.

## 6. Common Mistakes

Backpropagation menghitung gradien; **optimizer** yang melakukan pembaruan parameter. Jangan menyamakan keduanya. Learning rate terlalu besar bisa menyebabkan divergensi.
