# Perceptron

**Level:** Beginner | **Prasyarat:** Python Variables, Functions, dan konsep dasar Machine Learning.

## Tujuan Pembelajaran

Setelah belajar, kamu dapat menjelaskan konsep utama, membaca contoh perhitungannya, dan mengenali kesalahan yang sering terjadi.

## 1. Visual Intuition

![Ilustrasi Perceptron](/img/deep-learning/perceptron-diagram.png)

*Dua input dengan bobot dan bias menghasilkan skor sebelum fungsi step.*

## 2. Apa itu Perceptron?

Perceptron adalah model neuron dasar untuk keputusan biner. Input dikalikan weight lalu dijumlah dengan bias. Nilai ini masuk fungsi aktivasi langkah (*step function*).

## 3. Rumus

Rumus skor: `z = w1*x1 + w2*x2 + b`. Aktivasi langkah mengembalikan 1 jika `z >= 0`, dan 0 jika lebih kecil dari 0. Ini hanya salah satu konvensi threshold.

## 4. Hitung Manual

Jika `x1=1`, `x2=0`, `w1=0.8`, `w2=-0.4`, dan `b=-0.3`, maka `z=0.5`, sehingga output 1.

## 5. Keterbatasan

Perceptron satu layer tidak dapat merepresentasikan masalah XOR secara tepat bila hanya menggunakan batas keputusan linear pada input aslinya. Jaringan multi-layer dengan aktivasi non-linear dapat mengatasinya.

## 6. Common Mistakes

Jangan menyamakan perceptron sederhana dengan seluruh arsitektur Deep Learning. Hasil 0 atau 1 bukan probabilitas yang terkalibrasi.
