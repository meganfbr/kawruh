# Regularization And Early Stopping

**Level:** Beginner–Intermediate | **Prasyarat:** Python, NumPy dasar, dan Deep Learning Fundamentals.

Model yang sangat bagus di data train tetapi buruk pada data baru kemungkinan mengalami **overfitting**. Regularization mengurangi risiko ini dengan membatasi kompleksitas efektif atau mengatur proses training.

## Tujuan Pembelajaran

- Mengenali pola overfitting pada kurva loss.
- Menggunakan Dropout, L2, dan EarlyStopping.
- Memahami perbedaan regularization dan data augmentation.

![Overfitting dan EarlyStopping](/img/deep-learning/regularization-early-stopping.png)

## 2. Tiga Teknik Penting

| Teknik | Penjelasan |
| --- | --- |
| Dropout | Menonaktifkan sebagian aktivasi secara acak saat training |
| L2 Regularization | Menambahkan penalti nilai bobot ke fungsi objektif |
| Early Stopping | Menghentikan training saat metrik monitor tak lagi membaik selama sejumlah epoch |

## 3. Contoh Keras di Colab

```python
import tensorflow as tf

model = tf.keras.Sequential([
    tf.keras.Input(shape=(20,)),
    tf.keras.layers.Dense(32, activation='relu', kernel_regularizer=tf.keras.regularizers.l2(1e-4)),
    tf.keras.layers.Dropout(0.3),
    tf.keras.layers.Dense(1, activation='sigmoid'),
])
model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])

callback = tf.keras.callbacks.EarlyStopping(
    monitor='val_loss', patience=3, restore_best_weights=True,
)
# Untuk menjalankan training, siapkan X_train, y_train, X_val, y_val terlebih dahulu.
# history = model.fit(X_train, y_train, validation_data=(X_val, y_val),
#                     epochs=50, callbacks=[callback])
```

`Dropout(0.3)` menjatuhkan sekitar 30% aktivasi pada training (secara stokastik), bukan menghapus neuron permanen.

## 5. Common Mistakes

- Menggunakan EarlyStopping tanpa validation metric yang tersedia.
- Menganggap Dropout otomatis selalu meningkatkan accuracy.
- Meningkatkan regularization secara berlebihan sampai model underfitting.
