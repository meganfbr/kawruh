# Fashion MNIST Mini Project

**Level:** Beginner–Intermediate | **Prasyarat:** Python, NumPy dasar, dan Deep Learning Fundamentals.

Mini project ini membangun jaringan Dense untuk mengklasifikasikan gambar pakaian **Fashion MNIST** (28×28 piksel grayscale, 10 kelas). Tujuannya memahami end-to-end training, bukan mengejar akurasi tertinggi.

## Tujuan Pembelajaran

- Membuat model Dense dengan Keras.

### Sel 1 — Library dan Dataset

```python
import numpy as np
import tensorflow as tf
import matplotlib.pyplot as plt

tf.keras.utils.set_random_seed(42)
(X_full, y_full), (X_test, y_test) = tf.keras.datasets.fashion_mnist.load_data()

X_full = X_full.astype('float32') / 255.0
X_test = X_test.astype('float32') / 255.0

# Split dari data train resmi; test resmi tetap dipisahkan.
X_train, X_val = X_full[:50000], X_full[50000:]
y_train, y_val = y_full[:50000], y_full[50000:]
print(X_train.shape, X_val.shape, X_test.shape)
```

Data ini dinormalisasi dengan membagi 255 karena nilai piksel tersedia dalam rentang 0–255; operasi ini tidak mempelajari statistik dari data test.

### Sel 2 — Susun dan Compile Model

```python
model = tf.keras.Sequential([
    tf.keras.Input(shape=(28, 28)),
    tf.keras.layers.Flatten(),
    tf.keras.layers.Dense(128, activation='relu'),
    tf.keras.layers.Dropout(0.2),
    tf.keras.layers.Dense(10, activation='softmax'),
])
model.compile(
    optimizer='adam',
    loss='sparse_categorical_crossentropy',
    metrics=['accuracy'],
)
model.summary()
```

Karena label berbentuk integer 0–9, gunakan `sparse_categorical_crossentropy`. Lapisan `Flatten` meratakan 28×28 piksel menjadi vektor 784 nilai.

### Sel 3 — Training

```python
stop = tf.keras.callbacks.EarlyStopping(
    monitor='val_loss', patience=3, restore_best_weights=True,
)
history = model.fit(
    X_train, y_train,
    validation_data=(X_val, y_val),
    epochs=15,
    batch_size=128,
    callbacks=[stop],
    verbose=1,
)
```

### Sel 4 — Grafik Training

```python
plt.figure(figsize=(7, 4))
plt.plot(history.history['loss'], label='Train loss')
plt.plot(history.history['val_loss'], label='Validation loss')
plt.xlabel('Epoch')
plt.ylabel('Loss')
plt.legend()
plt.show()
```

### Sel 5 — Evaluasi dan Prediksi

```python
test_results = model.evaluate(X_test, y_test, return_dict=True, verbose=0)
print('Test metrics:', test_results)

class_names = ['T-shirt/top', 'Trouser', 'Pullover', 'Dress', 'Coat',
               'Sandal', 'Shirt', 'Sneaker', 'Bag', 'Ankle boot']
probabilities = model.predict(X_test[:1], verbose=0)[0]
pred_idx = int(np.argmax(probabilities))
print('Predicted class:', class_names[pred_idx])
print('True class:', class_names[int(y_test[0])])
print('Confidence (softmax):', round(float(probabilities[pred_idx]), 4))
```

Softmax menghasilkan skor yang jumlahnya 1, tetapi angka tersebut **tidak otomatis terkalibrasi** sebagai probabilitas dunia nyata.
