# Image Preprocessing

**Level:** Beginner–Intermediate | **Prasyarat:** Python, NumPy, dan dasar neural network.

## Tujuan Belajar

Memahami resizing, color channels, normalisasi, label, dan risiko *data leakage* pada dataset citra.

## 1. Mengapa preprocessing penting?

Model membutuhkan format tensor yang konsisten. Jika resolusi, rentang piksel, atau encoding label tidak sesuai, training bisa gagal atau hasil tidak dapat diandalkan.

| Langkah | Fungsi | Catatan |
| --- | --- | --- |
| Resize | Menyeragamkan ukuran | Bisa mengubah aspek rasio |
| RGB/grayscale | Menentukan jumlah kanal | RGB: 3, grayscale: 1 |
| Normalisasi | Menyesuaikan skala piksel | Sesuaikan dengan arsitektur pretrained |
| Split | Memisahkan train, validation, test | Hindari duplikat lintas split |
| Label mapping | Menetapkan ID kelas | Mapping harus konsisten |

## 2. Contoh preprocessing dengan TensorFlow (Colab)

```python
import tensorflow as tf

image = tf.io.read_file('contoh.jpg')
image = tf.image.decode_jpeg(image, channels=3)
image = tf.image.resize(image, [224, 224])
image = tf.cast(image, tf.float32) / 255.0
print(image.shape)
```

Ganti `contoh.jpg` dengan path gambar yang tersedia di runtime. **Jangan otomatis membagi 255** jika model pretrained memiliki fungsi preprocessing khusus atau mengharapkan skala berbeda.

## 3. Menghindari data leakage

- Lakukan pembagian data sebelum membuat augmentasi.
- Gambar duplikat atau hampir sama tidak boleh tersebar ke train dan test apabila mengukur generalisasi ke gambar independen.
- Jika gambar berasal dari pasien atau objek sama, pertimbangkan group split berdasarkan identitas sumber.
