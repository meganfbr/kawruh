# Activation Functions

**Level:** Beginner | **Prasyarat:** Python Variables, Functions, dan konsep dasar Machine Learning.

Pada materi ini kamu akan mempelajari prinsip **activation functions** dengan ilustrasi, contoh sederhana, dan latihan. Kita memisahkan simulasi Python murni dari kode deep learning menggunakan library khusus.

## Tujuan Pembelajaran

Setelah belajar, kamu dapat menjelaskan konsep utama, membaca contoh perhitungannya, dan mengenali kesalahan yang sering terjadi.

## 1. Visual Intuition

![Ilustrasi Activation Functions](/img/deep-learning/activation-functions.png)

*Kurva Sigmoid, Tanh, dan ReLU menunjukkan bentuk non-linear yang berbeda.*

## 2. Mengapa Membutuhkan Aktivasi?

Tanpa aktivasi non-linear di antara layer, komposisi transformasi linear tetap merupakan transformasi linear. Fungsi aktivasi memperkenalkan kemampuan untuk mempelajari pola non-linear.

## 3. Sigmoid

Sigmoid memetakan input ke interval (0,1), sehingga sering digunakan di output untuk klasifikasi biner. Pada nilai ekstrem, turunannya kecil dan dapat menyebabkan vanishing gradient.

## 4. Tanh

Tanh mengubah nilai ke (-1,1) dan berpusat di nol. Tanh juga dapat mengalami saturasi di nilai ekstrem.

## 5. ReLU

`ReLU(x) = max(0, x)` umum digunakan pada hidden layer karena sederhana dan efisien. Sebagian neuron dapat menjadi tidak aktif permanen pada kondisi tertentu (*dying ReLU*).

## 6. Memilih Fungsi Aktivasi

Pemilihan aktivasi output tergantung task: linear untuk banyak task regresi, sigmoid untuk klasifikasi biner, softmax untuk klasifikasi multi-kelas yang eksklusif. Hubungkan aktivasi output dengan loss yang sesuai.

## 7. Common Mistakes

Jangan selalu menaruh sigmoid di hidden layer. Jangan menganggap nilai sigmoid otomatis merupakan probabilitas yang terkalibrasi dengan baik.
