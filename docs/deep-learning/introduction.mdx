## 2. Apa itu Neural Network?

Neural network (jaringan saraf tiruan) adalah model yang mempelajari hubungan antara input dan target melalui parameter bernama **weights** (bobot) dan **biases**. Setiap layer mengubah informasi menjadi representasi yang dapat dipakai layer selanjutnya. Istilah *deep* mengacu pada penggunaan beberapa hidden layer.

## 3. Alur Forward Pass

1. Fitur masuk ke **input layer**. 2. Hidden layer melakukan perkalian bobot, penjumlahan bias, dan aktivasi. 3. **Output layer** menghasilkan prediksi. 4. **Loss function** mengukur kesalahan prediksi. Saat training, model memperbarui parameter untuk mengurangi loss.

## 4. Contoh Dua Fitur

Misalnya dua fitur adalah jumlah jam belajar dan kehadiran. Satu neuron sederhana dapat menghitung `z = jam * w1 + kehadiran * w2 + bias`. Nilai `z` kemudian diproses fungsi aktivasi. Nilai bobot contoh di sini ditentukan manual, **bukan hasil training**.

## 5. Istilah Penting

| Istilah | Arti |
|---|---|
| Feature | Variabel input model |
| Weight | Pengaruh relatif suatu fitur |
| Bias | Nilai tambahan sebelum aktivasi |
| Epoch | Satu putaran pelatihan melalui data training |
| Inference | Penggunaan model untuk membuat prediksi |

## 6. Common Mistakes

Neural network tidak selalu lebih unggul dari model sederhana. Performa dipengaruhi data, arsitektur, tuning, dan evaluasi yang adil. Jangan mengukur kualitas final menggunakan data training saja.
