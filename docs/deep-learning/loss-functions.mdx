# Loss Functions

**Level:** Beginner | **Prasyarat:** Python Variables, Functions, dan konsep dasar Machine Learning.

Pada materi ini kamu akan mempelajari prinsip **loss functions** dengan ilustrasi, contoh sederhana, dan latihan. Kita memisahkan simulasi Python murni dari kode deep learning menggunakan library khusus.

## Tujuan Pembelajaran

Setelah belajar, kamu dapat menjelaskan konsep utama, membaca contoh perhitungannya, dan mengenali kesalahan yang sering terjadi.

## 1. Visual Intuition

*MSE dan contoh binary cross-entropy memiliki bentuk penalti yang berbeda.*

## 2. Apa Itu Loss?

Loss function mengukur seberapa jauh prediksi model dari target selama pelatihan. Optimizer berusaha mengurangi loss pada data training; metrik evaluasi seperti accuracy atau F1 tetap perlu dilaporkan terpisah.

## 3. MSE untuk Regresi

Mean Squared Error adalah rerata kuadrat selisih prediksi dan target. `MSE = sum((y_true - y_pred)**2) / n`. Karena dikuadratkan, kesalahan besar mendapat penalti lebih tinggi.

## 4. MAE untuk Regresi

Mean Absolute Error menghitung rerata selisih absolut. Lebih mudah ditafsirkan dalam satuan yang sama dengan target dan sering lebih tahan terhadap outlier dibanding MSE.

## 5. Cross-Entropy untuk Klasifikasi

Untuk kasus biner: `- [y log(p) + (1-y) log(1-p)]`. Dalam praktik, gunakan implementasi numerik stabil seperti `BCEWithLogitsLoss` di PyTorch saat model mengeluarkan logits, alih-alih menghitung log manual tanpa clipping.

## 6. Loss vs Metric

**Loss** dipakai dalam optimisasi gradien. **Metric** dipakai untuk mengomunikasikan kualitas pada data validasi/test. Nilai loss yang kecil tidak menjamin distribusi kelas atau performa setiap kelas sudah baik.

## 7. Common Mistakes

Jangan menghitung cross-entropy dengan probabilitas tepat 0 tanpa perlindungan numerik. Jangan memilih loss klasifikasi untuk target regresi kontinu.
