# Model Validation And Evaluation

**Level:** Beginner–Intermediate | **Prasyarat:** Python, NumPy dasar, dan Deep Learning Fundamentals.

Validation digunakan untuk memantau performa selama pengembangan model, sedangkan test digunakan untuk evaluasi akhir pada data yang belum dipakai memilih konfigurasi.

## Tujuan Pembelajaran

- Menjelaskan peran train, validation, dan test.
- Menggunakan `evaluate()` dan `predict()`.
- Membaca hasil akurasi tanpa mengabaikan data leakage.

## 2. Validasi dalam Keras

Gunakan `validation_data=(X_val, y_val)` untuk mengukur metrik setiap epoch tanpa memperbarui bobot menggunakan contoh validation tersebut.

```python
history = model.fit(
    X_train, y_train,
    validation_data=(X_val, y_val),
    epochs=15,
)
```

Snippet di atas melanjutkan notebook yang sudah memiliki model dan data train/val. Untuk tutorial mandiri lengkap, gunakan [Mini Project Fashion MNIST](./fashion-mnist-mini-project).

## 3. Mengukur Hasil Akhir

```python
results = model.evaluate(X_test, y_test, return_dict=True, verbose=0)
print(results)
probabilities = model.predict(X_test[:5], verbose=0)
```

Pastikan kode dieksekusi setelah `model.compile` dan `model.fit` serta variabel `X_test`, `y_test` tersedia.

## 4. Hal yang Harus Dihindari

- Melihat hasil test berkali-kali untuk mengubah hyperparameter; test menjadi ikut memengaruhi keputusan.
- Menormalisasi dataset memakai statistik seluruh data sebelum split jika normalisasi bergantung pada statistik dataset.
- Membandingkan hanya accuracy pada dataset yang sangat tidak seimbang.
