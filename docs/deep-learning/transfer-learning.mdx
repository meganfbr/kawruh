# Transfer Learning

**Level:** Beginner–Intermediate | **Prasyarat:** Python, NumPy, dan dasar neural network.

## Tujuan Belajar

Memahami *pretrained encoder*, *feature extraction*, *fine-tuning*, dan penggunaan preprocessing sesuai model.

## 1. Mengapa transfer learning?

Model CNN yang sudah dilatih pada dataset besar dapat menjadi titik awal belajar pada dataset baru. Pada fase awal, bobot dasar dibekukan (*freeze*), sedangkan classifier baru dilatih. Setelah stabil, sebagian layer dapat di-*unfreeze* dan dilatih ulang dengan learning rate kecil.

![Transfer learning](/img/deep-learning/transfer-learning-workflow.png)

*Gambar 1. Encoder pretrained dihubungkan ke classifier yang sesuai jumlah kelas target.*

## 2. Contoh MobileNetV2 (Colab)

```python
import tensorflow as tf

base = tf.keras.applications.MobileNetV2(
    include_top=False,
    weights='imagenet',
    input_shape=(160, 160, 3),
)
base.trainable = False

inputs = tf.keras.Input(shape=(160, 160, 3))
x = tf.keras.applications.mobilenet_v2.preprocess_input(inputs)
x = base(x, training=False)
x = tf.keras.layers.GlobalAveragePooling2D()(x)
outputs = tf.keras.layers.Dense(3, activation='softmax')(x)
model = tf.keras.Model(inputs, outputs)
model.compile(optimizer='adam', loss='sparse_categorical_crossentropy', metrics=['accuracy'])
```

**Catatan:** di contoh ini model menerima gambar RGB pada rentang piksel yang diharapkan oleh `preprocess_input` MobileNetV2; jangan menambahkan normalisasi 0–1 terpisah sebelum langkah itu tanpa memeriksa kontraknya. Jumlah output `3` hanya contoh untuk dataset tiga kelas.

## 3. Feature extraction vs fine-tuning

| Fase | Backbone | Tujuan |
| --- | --- | --- |
| Feature extraction | Frozen | Melatih classifier baru |
| Fine-tuning | Sebagian layer dilatih | Adaptasi fitur tingkat tinggi |

Saat membuka layer untuk fine-tuning, **compile ulang model** agar optimizer mengetahui parameter trainable terbaru. BatchNormalization perlu perhatian khusus agar statistiknya tidak berubah tidak sengaja.
