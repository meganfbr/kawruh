## 2. Apa Itu Optimizer?

Optimizer menggunakan gradien untuk memperbarui parameter model supaya loss training berkurang. Perbaikan pada data training perlu terus diperiksa dengan data validasi.

## 3. Gradient Descent dan SGD

Pembaruan dasar adalah `w = w - lr * gradient`. *Stochastic Gradient Descent* pada praktik deep learning biasanya menerapkan pembaruan berdasarkan mini-batch. Learning rate menentukan ukuran langkah.

## 4. Momentum

Momentum menggabungkan informasi gradien sebelumnya untuk membantu pergerakan parameter, mengurangi osilasi pada beberapa permukaan loss.

## 5. Adam

Adam menggunakan estimasi momen pertama dan kedua gradien untuk menentukan skala update tiap parameter. Adam sering menjadi baseline kuat, tetapi tidak selalu unggul dari SGD untuk semua task.

## 6. Learning Rate Scheduler

Scheduler mengubah learning rate selama training, misalnya menguranginya setelah performa validasi tidak meningkat. Pilih kebijakan berdasarkan setup eksperimen dan hindari memantau test set untuk tuning.

## 7. Common Mistakes

Jangan berasumsi optimizer yang lebih kompleks pasti menghasilkan test score lebih baik. Evaluasi fairness memerlukan split, arsitektur, epoch, dan prosedur pemilihan model yang konsisten.
