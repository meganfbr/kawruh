# TensorFlow And Keras Introduction

**Level:** Beginner–Intermediate | **Prasyarat:** Python, NumPy dasar, dan Deep Learning Fundamentals.

TensorFlow adalah library untuk komputasi numerik dan Machine Learning. **Keras** adalah antarmuka tingkat tinggi yang memudahkan kita merakit, melatih, dan mengevaluasi neural network. Pada course ini kita memakai `tf.keras` untuk menjaga contoh kode konsisten.

## 3. Model Pertama dengan Sequential

Salin kode ini ke Colab. Kita membuat contoh klasifikasi dua kelas dari empat fitur numerik **sintetis**.

```python
import numpy as np
import tensorflow as tf

tf.keras.utils.set_random_seed(42)
rng = np.random.default_rng(42)
X = rng.normal(size=(400, 4)).astype('float32')
y = ((X[:, 0] + X[:, 1] * 0.5) > 0).astype('float32')

X_train, X_test = X[:320], X[320:]
y_train, y_test = y[:320], y[320:]

model = tf.keras.Sequential([
    tf.keras.Input(shape=(4,)),
    tf.keras.layers.Dense(16, activation='relu'),
    tf.keras.layers.Dense(1, activation='sigmoid'),
])
model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])
model.fit(X_train, y_train, epochs=10, batch_size=32, verbose=1)
print(model.evaluate(X_test, y_test, verbose=0))
```

Ini contoh pembelajaran sintaks; split berurutan di sini tidak menggantikan praktik split acak/stratifikasi yang tepat untuk eksperimen sungguhan.

## 4. Memahami Lima Istilah Penting

| Istilah | Fungsi |
| --- | --- |
| `Sequential` | Menumpuk layer secara berurutan |
| `compile()` | Menentukan loss, optimizer, dan metrik |
| `fit()` | Melatih bobot model |
| `evaluate()` | Menghitung metrik pada data evaluasi |
| `predict()` | Menghasilkan prediksi untuk input baru |

## 6. Common Mistakes

- Menganggap akurasi train sama dengan kemampuan generalisasi model.
- Menggunakan `binary_crossentropy` pada target multi-kelas yang dikodekan integer tanpa menyesuaikan output dan loss.
- Menyimpulkan model bagus hanya karena `fit()` selesai tanpa error.
